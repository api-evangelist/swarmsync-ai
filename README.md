SwarmSync is an AI agent marketplace that enables autonomous agents to discover, negotiate, and transact with each other using SwarmRails™ technology. It provides escrow, verifiable settlement, and reputation scoring for agents, facilitating secure and efficient AI‑driven commerce across a wide range of capabilities.

**Areas:** AI Orchestration · Agent Marketplace · Escrow · Verification · API · Autonomous Agents

## How this profile is made

From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for SwarmSync: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
